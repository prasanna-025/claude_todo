SQL Mastery & Top 10 Accenture Query Patterns

1. 2nd / Nth Highest Salary
-- Method 1: Subquery
SELECT MAX(salary) AS SecondHighestSalary
FROM Employees
WHERE salary < (SELECT MAX(salary) FROM Employees);

-- Method 2: Nth Highest (For 2nd, OFFSET 1)
SELECT DISTINCT salary
FROM Employees
ORDER BY salary DESC
LIMIT 1 OFFSET 1;
2. WHERE vs HAVING Difference
• WHERE: Filters rows before grouping. Cannot use aggregates.
• HAVING: Filters groups after GROUP BY. Can use SUM(), COUNT(). 
SELECT dept, AVG(salary) 
FROM Employees 
WHERE status = 'Active' 
GROUP BY dept 
HAVING AVG(salary) > 50000;
3. Employees Earning More Than Their Manager
SELECT E.name AS Employee
FROM Employees E
JOIN Employees M ON E.manager_id = M.id
WHERE E.salary > M.salary;
4. Find & Delete Duplicate Emails
-- Find Duplicates
SELECT email, COUNT(*) AS count
FROM Users GROUP BY email HAVING COUNT(*) > 1;

-- Delete Duplicates (Keep Lowest ID)
DELETE p1 FROM Person p1
JOIN Person p2 
WHERE p1.email = p2.email AND p1.id > p2.id;
5. Customers Who Never Ordered (LEFT JOIN NULL check)
SELECT C.name AS Customers
FROM Customers C
LEFT JOIN Orders O ON C.id = O.customer_id
WHERE O.customer_id IS NULL;
6. CASE Conditional Update (Swap 'm' & 'f')
UPDATE Salary
SET sex = CASE 
            WHEN sex = 'm' THEN 'f' 
            ELSE 'm' 
          END;

Pseudocode Tracing & Bitwise Operators

Bitwise Operator Reference
OpNameRule / Shortcut
&AND1 only if both bits are 1
|OR1 if at least one bit is 1
^XOR1 if different; a ^ a = 0, a ^ 0 = a
~NOT~x = -(x + 1) (e.g. ~5 = -6)
<<Left Shifta << b = a * 2^b (3 << 2 = 12)
>>Right Shifta >> b = floor(a / 2^b) (16 >> 2 = 4)

Information & Network Security

Encryption & CIA Triad
• CIA: Confidentiality (Encryption), Integrity (Hashing), Availability (Redundancy/DDoS defense).
• Symmetric: 1 shared key. Fast. (AES, DES, 3DES).
• Asymmetric: Public + Private key pair. (RSA, ECC, Diffie-Hellman).
• Hashing: One-way irreversible (MD5, SHA-256).
Threats & Wi-Fi Security
• Virus: Needs host program + user execution.
• Worm: Self-replicating over network without user action.
• Trojan: Disguised harmful software.
• Wi-Fi Protocol Strength: WEP (Weakest) < WPA < WPA2 (AES) < WPA3 (Strongest).

OOP Core Principles

1. Encapsulation
Data hiding. Wrapping data & methods inside a class; private variables with getters/setters.
2. Abstraction
Hiding implementation details and showing only necessary interfaces (Abstract classes, Interfaces).
3. Inheritance
Child class inheriting properties of parent class for code reusability (extends).
4. Polymorphism
Overloading (Compile-time: same name, different params) vs Overriding (Run-time: exact same signature in child).
