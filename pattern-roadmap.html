Core Concepts to Master:

The 8-Step Problem Solving Rule

1
Read Carefully Twice
Notice edge conditions: negatives, empty arrays, single elements, odd/even constraints.
2
Identify the Pattern & Inputs
Is it contiguous? (Sliding window / Prefix sum). Sorted? (Two pointers / Binary search). Next greater? (Monotonic stack).
3
Dry-Run on Paper First
Trace standard and edge test cases manually before opening the code editor.
4
State Time & Space Complexity
Know the target complexity: O(N) or O(N log N). Avoid O(N²) when N ≥ 10⁵.
5
Write Clean, Modular Code
Use self-descriptive variable names and write idiomatic Python/C++/Java.
6
Check Off-By-One Errors
Verify 0-indexed loops, inclusive/exclusive boundaries in binary search and sliding windows.
7
Save Notes & Code Proof
Document the key insight or tricky bug in the Notes drawer so you never forget it during revision.
8
Repeat Spaced Repetition
Re-solve tagged difficult problems after 7 days without looking at your solution.
